The Git + filesystem paradigm was designed for a world where humans wrote code slowly and collaboration was low-concurrency.
In a world with hundreds of autonomous coding agents producing code continuously, code is no longer static text—it is high-velocity structured data.
The correct abstraction is no longer files and commits, but transactions, invariants, subscriptions, and graph-structured codebases.
Instead of asking how to scale Git workflows, we should ask: what is the machine-native substrate for software development?
